# 전투 연출 강화 기획안 (개정판)

> **1차 기획안이 방향을 잘못 잡아 개정.** 타이밍(손맛)만 다뤘으나, 실제 요구는
> **"캐릭터 그림이 제대로 움직이는 것"** — 달려가는 그림, 몸을 휘두르는 그림, 베이는 그림.
> 애니메이션 프레임 확충을 1순위로 재배치한다.

---

## 0. 현재 상태 (냉정하게)

**스프라이트가 사실상 2장뿐이다.**

| 포즈 | 현재 | 문제 |
|---|---|---|
| 대기 | 2프레임 (상체 1px 위아래) | 호흡만. OK |
| 달리기 | **없음** — 대기 프레임 재사용 | 미끄러져 이동하는 것처럼 보임 |
| 공격 | **1프레임** (무기 수평으로 뻗음) | 휘두르는 게 아니라 뻗은 채 정지 |
| 피격 | **없음** — 흰 플래시만 | 맞은 티가 안 남 |
| 시전 | **없음** — 공격 포즈 재사용 | 마법 쓰는 느낌 없음 |

**그리고 절반의 캐릭터는 아예 움직이지 않는다.**
`melee` 플래그가 없는 스킬(활·지팡이 계열)은 제자리에서 파티클만 뜬다.

| 제자리 공격 | 해당 인원 |
|---|---|
| 궁수 3명 (루멘·나딘·팔크) + 마법사 2명 (카시안·에라) + 성직자 3명 (세라핀·미엘·테오) | **아군 15명 중 8명** |
| 적: 해골 궁수, 암흑 주술사 | |

→ 화살도 마법탄도 **날아가는 게 없다.** 쏘는 동작도 없다. 그래서 "툭 치고 데미지"로 보인다.

## 1. 스프라이트 애니메이션 확충 ★최우선

코드 생성 방식이라 **포즈를 하나 추가하면 15명 전원에게 자동 적용**된다. 이게 이 프로젝트의 강점.

### 1-1. 포즈 세트 (전 캐릭터 공통)

| 포즈 | 프레임 | 내용 |
|---|---|---|
| `idle` | 2 | 호흡 (기존) |
| `run` | **4** | 다리 교차 + 상체 앞으로 기울임 + 팔 흔들림 |
| `attack` | **4** | 무기별 스윙 시퀀스 (아래) |
| `cast` | **3** | 시전: 무기 들어올림 → 발광 → 방출 |
| `hurt` | **2** | 뒤로 젖혀짐 + 무기 흘러내림 |
| `down` | **2** | 무릎 꿇음 → 쓰러짐 (현재는 회전으로 대체 중) |

프레임 수 합계 캐릭터당 약 30장(32×32). 로드 시 프리렌더 1회 — 성능 영향 없음(절대 규칙 7 준수).

### 1-2. 무기별 공격 스윙 (4프레임)

**핵심: 무기가 실제로 호를 그리며 지나가야 한다.**

| 무기 | 1 예비 | 2 스윙 | 3 임팩트 | 4 잔심 |
|---|---|---|---|---|
| **대검·도끼** | 머리 위로 치켜듦 | 사선으로 내려침(45°) | 무기가 아래 끝, 상체 앞으로 숙임 | 천천히 복원 |
| **창** | 뒤로 당김, 몸 낮춤 | 앞으로 찌름 | 팔 완전히 뻗음 | 회수 |
| **쌍단검** | 양팔 교차 | 오른손 벰 | 왼손 벰 (2연타) | 웅크림 |
| **활** | 시위 당김(팔 뒤로) | 놓음 | 반동으로 상체 젖힘 | 복원 |
| **지팡이** | 위로 들어올림 | 끝에 빛 응집 | 앞으로 내리치며 방출 | 복원 |
| **뼈몽둥이**(적) | 위로 | 옆으로 후려침 | 끝 위치 | 복원 |

### 1-3. 달리기 (4프레임)

다리 교차 2단계 + 상체를 진행 방향으로 8° 기울임 + 반대 팔 흔들림. 돌진·복귀 시 재생.
복귀할 때는 **뒷걸음이 아니라 몸을 돌려 달려 돌아온다**(스프라이트 좌우 반전).

### 1-4. 피격 반응 (2프레임)

- 1프레임: 상체가 뒤로 젖혀짐 + 고개 뒤로 + 무기 내려감
- 2프레임: 반쯤 복원
- 여기에 기존 넉백·플래시·찌그러짐을 겹친다

## 2. 타격 이펙트 — "베이는 모션" ★

대상 스프라이트를 바꾸는 게 아니라, **대상 위에 궤적을 그린다.** 이게 베이는 느낌의 실체.

| 무기·속성 | 이펙트 |
|---|---|
| 대검·도끼 | **굵은 초승달 참격**이 대상을 사선으로 가로지름 (흰색 → 속성색, 2프레임 확대 후 소멸) |
| 창 | **관통선** — 대상을 뚫고 지나가는 직선 + 끝점 스파크 |
| 쌍단검 | **X자 교차 참격** 2연속 |
| 활 | **꽂히는 화살** — 대상에 잠깐 박혀 있다가 사라짐 |
| 마법 | 속성색 **폭발 + 잔재 파티클** (불=불티, 물=얼음 파편, 땅=돌조각) |
| 치유 | 상승하는 **빛 기둥 + 반짝임** |

참격 궤적은 캔버스 도형(호·다각형)으로 그린다 — 스프라이트 불필요, 크기·각도 자유.

---

## 3. 원거리 투사체 ★ (지금 완전히 없음)

| 종류 | 연출 |
|---|---|
| 화살 | 회전 없이 진행 방향 유지, 뒤에 잔상 2개, 0.15초 비행 |
| 마법탄 | 속성색 구체 + 꼬리 파티클, 살짝 흔들리며 비행 |
| 광역 마법 | 시전자 위에서 시작 → 적 진영 상공 → 낙하 |
| 치유 | 시전자 → 대상으로 빛 입자가 흘러감 |

**비행 중에는 시전자가 `cast` 포즈를 유지**하고, 착탄 시점에 히트스톱·이펙트가 터진다.
이것만으로 궁수·마법사 8명의 체감이 완전히 달라진다.

## 4. 스킬 등급별 차등

| 등급 | 연출 |
|---|---|
| 일반공격 | 예비 → 달리기 → 스윙 4프레임 → 참격 → 복귀. 약 0.6초 |
| 액티브 | + 시전 시 캐릭터 발광, 스킬명 배너, 확대된 이펙트. 약 0.9초 |
| 성물·필살기 | + 배경 암전, 캐릭터만 스포트라이트, 화면 확대, 대형 이펙트, 긴 히트스톱. 약 1.5초 |

## 5. 타이밍 보강 (1차 기획안 유지분)

애니메이션이 들어간 뒤에 얹어야 효과가 난다.

- **히트스톱**: 타격 순간 정지. 일반 4프레임 / 액티브 6 / 성물·치명타 10 / 처치 14
- **모션 곡선**: 예비(뒤로 빼기) → 급가속 돌진 → 정지 → 감속 복귀
- **피격 찌그러짐**: 가로 1.25배 × 세로 0.8배 → 3프레임 복원
- **넉백**: 피해량 비례 (최대 28px), 탄성 복귀
- **화면 흔들림**: 모든 타격에 미세하게(2px) + 타격 방향 지향성
- **데미지 팝업**: 튀어오르며 확대 후 축소
- **2배속 호환**: 히트스톱만 배속 영향 60%만 받게 (그대로 절반이 되면 손맛 소실)

## 7. 기술 메모

- 포즈 추가는 `core/sprites.js`의 `makeUnitSprites`에 그리기 분기를 늘리는 것 — 데이터(캐릭터 정의)는 손대지 않는다
- 모든 포즈는 **로드 시 1회 프리렌더**, 재생은 배열 인덱스 참조 (절대 규칙 7)
- 참격 궤적·투사체는 스프라이트가 아니라 **캔버스 도형**으로 — 각도·크기 자유롭고 메모리 0
- 연출 타이밍 상수는 밸런스 수치가 아니므로 `balance.js`가 아니라 별도 `fx.js`에 모은다
- 파티클·투사체는 오브젝트 풀 재사용
