# 1부. 이 게임이 어떤 게임인가

## 한 줄 요약
**정통 판타지 수집형 JRPG.** 마왕에게 멸망한 왕국을 재건하며, 흩어진 영웅 15명을 모아 싸우는 이야기.

## 분위기
- **밝음이 기본, 중요한 순간에 진지해진다.** 어둡고 무거운 게임이 아니다. 동료들끼리 농담하고, 요새가 조금씩 되살아나는 걸 지켜보는 따뜻함이 중심이다.
- 다만 **4~5장은 묵직하다.** 왕국 멸망의 진실이 밝혀지고, 배신자와 마주하고, 마왕이 사실은 인간에게 배척당한 피해자였다는 게 드러난다.
- 마지막은 **마왕을 죽이지 않고 구원하는 엔딩**이다. 복수극이 아니라 화해의 이야기.

## 톤 레퍼런스
고전 JRPG의 픽셀아트 초상. 데포르메(2~3등신)가 아니라 **적당히 사실적인 비율의 버스트업**. 과도하게 귀엽거나 과도하게 어둡지 않은, 정통 판타지의 단정한 느낌.

## 화면에서 초상이 어떻게 쓰이나

**① 대화 장면 (가장 많이 보임)**
화면 좌우에 초상이 서고 아래에 텍스트 박스가 뜬다. 말하는 쪽이 밝고 선명하게, 안 말하는 쪽은 어둡게 처리된다.

```
┌──────────────────────────────┐
│  [초상]              [초상]   │   ← 좌우 배치
│                              │
│ ┌──────────────────────────┐ │
│ │ 세레스                    │ │   ← 이름표
│ │ 이곳이 새벽별 요새예요.    │ │   ← 대사
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

**② 스킬 컷인 (전투 중)**
강한 스킬을 쓰면 화면이 어두워지고 **초상이 대각선으로 슬라이드해 들어온다.** 속도선 배경 위에 얹히고, 이때는 `진지` 표정을 쓴다. 확대돼서 보이므로 **얼굴이 화면을 채운다.**

**③ 뽑기 연출**
새 동료를 얻으면 소환진에서 빛이 터지며 초상이 공개된다. ★3는 금색 대폭발과 함께.

**④ 캐릭터 상세·파티 편성 화면**
목록에서 작게, 상세 화면에서 크게 표시된다.

# 2부. 기술 규격

## 필수 사양

| 항목 | 값 |
|---|---|
| 크기 | **96 × 96 픽셀** |
| 형식 | **PNG, 배경 투명(알파)** |
| 스타일 | **픽셀아트** (안티에일리어싱 없이, 도트 단위로 선명하게) |
| 구도 | **버스트업** — 가슴 위. 얼굴이 화면의 60~70% |
| 표정 | 캐릭터당 **3종**: `기본` / `웃음` / `진지` |
| 색 | **아래 팔레트 32색 + 속성색 안에서만** ★가장 중요 |

## 왜 96×96인가

게임 기준 해상도가 960×540이고, 초상은 화면의 1/5 정도를 차지한다. 화면이 커지면 **정수배로 확대**되므로(2배·3배) 도트가 흐려지지 않는다. 그래서 원본은 정확히 96×96이어야 한다.

**96×96은 생각보다 작다.** 눈·코·입이 각각 2~6픽셀 수준이다. 세밀한 묘사보다 **실루엣과 색으로 캐릭터를 구분**하는 게 핵심이다. 머리 모양, 머리색, 옷 색, 소품(안경·모자·무기 손잡이)으로 알아보게 만든다.

## 안전 영역

```
     96px
 ┌───────────┐
 │  여백 6px  │  ← 상단: 머리 잘리지 않게
 │ ┌───────┐ │
 │ │  얼굴  │ │  ← 이 영역에 얼굴 (핵심)
 │ │       │ │
 │ ├───────┤ │
 │ │ 어깨·가슴│ │  ← 하단 12px은 텍스트 박스에 가려질 수 있음
 │ └───────┘ │     중요한 요소를 두지 말 것
 └───────────┘
```

# 3부. 공통 아트 디렉션

## 그리는 방식

**외곽선**: 있음. `black #0d0b14` 또는 해당 부위의 가장 어두운 색으로. 굵기 1픽셀.

**명암**: 픽셀아트답게 **단계를 나눈다.** 그라데이션이 아니라 2~3단계 색 면으로. 광원은 **화면 좌측 위**에서 온다고 가정.

**디테일 밀도**: 얼굴에 집중. 옷은 실루엣과 큰 색면 위주로 단순하게. 96×96에서 옷 주름을 그리면 지저분해진다.

**시선**: 정면 또는 살짝 측면(4분의 3). 대화 상대를 보는 느낌.

## 배치 주의

초상은 **좌우 양쪽에 다 나올 수 있다.** 게임에서 자동으로 좌우 반전하지 않으므로, 어느 쪽에 놓여도 자연스럽도록 **정면에 가까운 구도**로 그린다. 강하게 옆을 보는 구도는 피할 것.

## 등급 표현

★3 캐릭터는 장식을 조금 더 화려하게(금색 포인트, 망토 등), ★1은 소박하게. 다만 **과하게 차이 내지 말 것** — ★1도 주력으로 쓰는 플레이어가 많다.

# 4-2부. ★ 전투 스프라이트 (전신) — 작업의 본체

> 초상(4부)과 별개로, **게임에서 실제로 움직이는 전신 도트**입니다.
> 플레이 시간의 대부분을 여기서 보내므로 체감이 가장 큽니다.

## 기본 규격

| 항목 | 값 |
|---|---|
| 크기 | **32 × 32 픽셀** |
| 형식 | PNG, 배경 투명 |
| 화면 표시 | 3배 확대(96px)되어 보임 — 도트 하나가 3픽셀로 커진다 |
| 방향 | **측면(옆모습) 1방향만** — 게임이 좌우 반전을 자동 처리 |
| 기준선 | **발끝을 캔버스 맨 아래(31번째 줄)에 맞출 것** ★필수 |

**왜 측면만?** 전투는 사이드뷰라 아군은 오른쪽, 적은 왼쪽을 봅니다. 한 방향만 그리면 게임이 뒤집어서 씁니다.

**기준선이 왜 중요한가**: 프레임마다 발 위치가 다르면 캐릭터가 위아래로 튑니다. **모든 프레임에서 발끝 높이를 동일하게** 맞춰 주세요. (공중에 뜨는 동작은 예외)

## 필요 포즈 (캐릭터당 14장)

| 포즈 | 장수 | 설명 |
|---|---|---|
| **대기** | 2 | 호흡. 상체가 1픽셀 위아래로 (가장 오래 보임) |
| **걷기/달리기** | 4 | 다리 교차 + 상체 앞으로 기울임 + 팔 흔들림. **필드 이동에도 재사용** |
| **공격** | 4 | 무기별 스윙 (아래 표 참조) |
| **시전** | 2 | 무기를 들어올림 → 끝에 빛 응집 (마법·활 시전) |
| **피격** | 1 | 상체가 뒤로 젖혀짐, 무기 흘러내림 |
| **쓰러짐** | 1 | 무릎 꿇거나 옆으로 넘어짐 |

## ★ 프레임별 정확한 동작

**기준**: 캐릭터는 **오른쪽을 보고** 서 있습니다. "앞"은 오른쪽, "뒤"는 왼쪽입니다.
32×32 안에서 대략 머리 y0~10, 상체 y10~22, 다리 y22~31입니다.

### 대기 (2장) — 가장 오래 보이는 자세

| # | 동작 |
|---|---|
| **1** | 옆으로 서서 앞을 봄. 무기는 아래로 내리거나 어깨에 걸침. 두 발은 살짝 벌리고 무게중심 중앙. **이 캐릭터의 기본 실루엣** |
| **2** | 1번과 동일하되 **상체·머리·무기를 통째로 1픽셀 아래로**. 다리는 고정. (숨 내쉬는 순간) |

> 대기는 2장의 차이가 1픽셀뿐입니다. 다리를 움직이면 떨려 보이니 **상체만** 움직이세요.

### 걷기·달리기 (4장) — 전투 돌진 + 필드 이동 공용

앞으로 달려가는 동작입니다. 상체를 **앞으로 8도쯤 기울이고**, 팔은 다리와 반대로 흔듭니다.

| # | 동작 |
|---|---|
| **1** (접지) | 앞발을 크게 앞으로 뻗어 착지. 뒷발은 뒤에. **뒤쪽 팔이 앞으로**, 앞쪽 팔은 뒤로 |
| **2** (교차) | 두 다리가 몸 아래에서 겹침. **몸 전체가 1픽셀 위로** (뛰어오른 순간) |
| **3** (반대 접지) | 1번의 반대. 반대쪽 발이 앞, 팔도 반대 |
| **4** (교차) | 2번과 같은 자세, 몸 1픽셀 위 |

> 2장으로 줄이면 **1번과 3번**만 쓰시면 됩니다.

### 공격 4장 — 무기가 실제로 호를 그려야 합니다

| **2 스윙** | 검이 위에서 앞으로 **45도 사선 이동 중**. 상체가 앞으로 회전하기 시작. 검이 가장 빠른 순간 |
| **3 임팩트** | 검이 **앞쪽 아래 끝**(무릎 높이). 상체 완전히 앞으로 숙임. 앞발 내딛음. **가장 힘이 실린 프레임** |
| **4 잔심** | 검을 반쯤 회수, 상체 절반만 복원. 대기 자세로 이어지는 중간 |

# 4-3부. ★ 필드 스프라이트 (탑다운 걷기) — 2026-08-03 추가

## 지금 상태

**주인공 옆모습은 이미 있습니다** (4-2부의 걷기 4프레임을 그대로 씁니다).

지금은 임시로 옆모습을 돌려 쓰고 있어서, 위아래로 걸으면 옆을 본 채 움직입니다.

## 기본 규격 — 전투와 똑같습니다

| 항목 | 값 |
|---|---|

```
pixel art character portrait, bust shot, 96x96 pixels, retro JRPG style,

```

```

```

## AI 결과물 후처리 (필수)

AI는 팔레트를 안 지키고 안티에일리어싱이 들어갑니다. 그래서:

1. **크게 생성** (512×512 등) 후 **96×96으로 축소** (nearest neighbor)
2. **팔레트 강제 적용** — Aseprite나 온라인 도구로 위 32색에 양자화(quantize)
3. **배경 제거** → 투명 PNG
4. 외곽선·눈 등 **주요 부위는 손으로 다듬기**

> AI 시안은 **방향 잡는 용도**로 쓰고, 최종본은 손으로 정리하는 걸 권합니다. 팔레트가 안 맞으면 게임 화면에서 확실히 티가 납니다.
