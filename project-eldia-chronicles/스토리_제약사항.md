# 스토리 집필 제약사항 — "이건 바꾸면 개발이 깨집니다"

> 집필자에게 함께 전달할 문서. 자유롭게 창작해도 되는 것과, 건드리면 시스템 재설계가 필요한 것을 구분한다.
> 🔴 = 절대 불가 · 🟡 = 가능하지만 개발 작업 발생 · 🟢 = 자유

---

## 🔴 1순위 함정 — 이게 제일 많이 실수합니다

### ① 동료 15명은 "뽑기"로 얻는다 → 스토리에 등장을 전제할 수 없다

**가장 중요한 제약입니다.** 브란·세라핀·에라 등 15명은 전부 **뽑기(소환)로만** 얻습니다.
즉 플레이어에 따라 **1장에서 브란을 가진 사람도 있고, 끝까지 못 뽑은 사람도 있습니다.**

그래서 다음은 **쓸 수 없습니다**:
- ❌ "3장에서 브란이 파티에 합류한다"
- ❌ "카시안이 유적을 해석해 주었다" (카시안이 없는 플레이어는 진행 불가)
- ❌ "세라핀이 부상자를 치료했다" (없을 수 있음)

**쓸 수 있는 방법 3가지** (셋 중 택일해서 표기해 주세요):
| 방식 | 표기 | 설명 |
|---|---|---|
| **게스트 등장** | `[게스트]` | 파티 보유와 무관하게 **그 씬에만** 나타난다. 스토리에는 있지만 전투에는 안 나옴 |
| **조건부 대사** | `[보유 시]` | 그 동료를 가진 플레이어에게만 보이는 추가 대사. 없어도 진행에 지장 없음 |
| **개인 서사로 이전** | — | 그 캐릭터의 깊은 사연은 **호감도 Lv3 전용 퀘스트**로 (거기선 보유가 전제되므로 안전) |

> 예: 3장의 브란 서사는 **브란을 [게스트]로 등장**시키면 해결됩니다. 파티에 없어도 이야기에는 나옵니다.

### ② 동료는 죽거나 영구 이탈할 수 없다

플레이어가 뽑아서 키운 캐릭터가 스토리 때문에 사라지면 안 됩니다(육성 자원이 증발).
- ❌ "○○가 희생한다" / "○○가 파티를 떠난다"
- ⭕ 위기·중상·일시적 이탈 후 복귀는 가능

### ③ 주인공은 이름·성별·직업이 플레이어 선택이다

- 이름은 입력값 → 대사에 항상 `{주인공}` 치환자 사용
- 성별 선택 → **성별이 드러나는 표현 금지** (그/그녀, 소년/소녀, 형/누나 등)
- 직업 3택(검사·마법사·궁수) → **무기가 드러나는 서술 금지** ("검을 뽑아 들었다" ❌ → "루체른을 겨눴다" ⭕)
- 주인공 대사는 가능하지만 **성격이 고정되지 않게** 중립적으로

### ④ 왕녀 세레스는 전투에 참여하지 않는다

거점 총괄 NPC입니다. 동행·조언은 되지만 **전투 장면에서 싸우는 묘사는 불가**합니다.

## 🔴 숫자·구조 (바꾸면 시스템 재설계)

| 항목 | 고정값 | 바뀌면 생기는 일 |
|---|---|---|
| 동료 수 | **15명** | 뽑기 확률표·천장·등급 분포·완돌 목표·도감 슬롯 전부 재계산 |
| 등급 분포 | ★3=4명 / ★2=6명 / ★1=5명 | 위와 동일 |
| 속성 분포 | 불3 물3 바람3 땅3 빛2 어둠1 | 상성 밸런스 붕괴 |
| 직업 분포 | 전사3 기사2 궁수3 마법사2 성직자3 도적2 | 파티 조합 밸런스 붕괴 |
| 파티 인원 | **주인공 + 3 = 4인** | 전투 화면 진형·UI·편성 전부 재작업 |
| 속성 | **6종** (불·물·바람·땅·빛·어둠) | 상성 순환표·각성석 6종·정령 시련·색상 전부 재설계 |
| 정령왕 | **6명** (= 속성 6종과 1:1) | 주인공 각성 단계와 연동되어 깨짐 |
| 직업 | **6종** | 스탯표·무기 6계열·방어구 3계열 재설계 |
| 주인공 직업 | **3택** (검사·마법사·궁수) | 직업당 스킬 4개+성물 스킬+스프라이트 추가 필요 |
| 챕터 | **5장 + 종장** | 레벨 60 곡선·장비 티어 6·시설 해금·성벽 5단계 전부 재배분 |
| 표정 | **3종** (기본/웃음/진지) | 15명 × 추가 표정 전부 다시 제작 |
| 스킬 구조 | 일반1 + 액티브2 + 패시브1 (주인공만 +성물1) | 스킬 카드 UI가 최대 3장 기준 |

## 🟡 가능하지만 개발 작업이 생기는 것

| 항목 | 현재 | 늘리면 |
|---|---|---|
| 장당 스토리 전투 | 5회 + 던전(3+보스) | 스테이지 데이터·경험치 곡선 조정 |
| 보스 | 6종 (5장 + 최종) | 기믹 1종당 별도 구현 |
| 몬스터 | 32종 | 스프라이트·스탯·AI 추가 |
| 상태이상 | 14종 | 새 효과는 로직 추가 |
| 서브퀘스트 | 챕터당 7개 | 데이터 추가로 가능(비교적 쉬움) |
| 재화 | 11종 | 새 재화는 UI·저장 구조 추가 |

**새 시스템을 요구하는 전개는 미리 알려 주세요.** 예를 들어 "이 장면에서 배를 타고 이동한다", "특정 아이템을 조합한다" 같은 건 없는 기능입니다.

## 🟡 전투 묘사 주의

이 게임은 **JRPG 사이드뷰 턴제**입니다. 아군은 왼쪽, 적은 오른쪽에 서고 공격할 때만 가로로 돌진합니다.

- ⭕ 쓸 수 있는 용어: **연계 협공**(같은 적을 이어 치면 동료가 추가타), **반격**, **표식**, **속성 상성**, **성물 각성**
- ❌ 없는 개념: 격자·칸·이동력·사거리·배후 공격·측면·진형 이동·엄폐

## 🟢 마음껏 자유인 것

- **모든 이름**: 재상, 정령왕, NPC, 주민, 마을·유적·지명
- **대사 전부**: 톤·유머·말투 (캐릭터 성격표만 지켜 주면)
- **사건 전개와 조연 에피소드**
- **복선 배치와 회수 방식**
- **캐릭터 배경 서사** (아래 단서 조항만 주의)

### 단, 캐릭터 성격을 크게 바꾸면 스킬과 안 맞습니다
스킬은 이미 성격 기반으로 설계되어 있습니다.
- 세라핀: **자기 HP를 깎아 치유**하는 스킬 → "자기희생적" 성격이 전제
- 브란: **도발로 아군을 지키는** 스킬 → "방패" 성격이 전제
- 녹스: **은신·급소** 스킬 → "암살자" 성격이 전제
- 로크: **자기 방어를 깎고 강타** → "단순무식" 성격이 전제

성격을 반대로 바꾸면 스킬을 다시 설계해야 합니다.
