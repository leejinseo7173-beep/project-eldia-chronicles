# 1장 완성 기획 — "왕국은 죽지 않았다"

> 2026-08-24 작성. 상태: **사용자 검토 대기**.
> 방향 전환 (사용자 결정): **1장까지만 완성한다. 2장 이후는 완전 나중에.**
> 문제 진단 (사용자): 채집은 건설 비용에 비해 무의미하고, 전투는 "굳이 왜?"가 없다.
> → 원인은 콘텐츠 부족이 아니라 **인과 부재**: 시스템(전투·채집·건설·뽑기)은 다 있는데
> 그걸 잇는 스토리 목표가 없다. 1장 스토리 퀘스트 체인이 그 접착제다.

---

## 1. 스코프 선언

- **만든다**: 프롤로그 → 1장 엔딩("왕국은 죽지 않았다")까지 끊김 없이 플레이되는 게임
- **안 만든다**: 2장~종장, 서브퀘스트, 파밍 던전, 엔드게임, 업적, 도감
- M6의 재정의: "수직 슬라이스" = **1장 그 자체**. 1장이 곧 게임의 축소판이 된다

### 승인점 ① — 1장 적 = 마왕군 5종 유지 (기획서 변경)

기획서 §8은 1장 지역몹을 고블린·늑대 등 5종으로 정의하지만, **1장 적은 현재 완성된
마왕군 5종(해골 병사·궁수·주술사·살수·망령 기사)을 그대로 쓴다.**
- 스토리가 오히려 정합: 1장의 위협은 "새벽 평원에 주둔한 **마왕군 선발대**"다.
  들판의 고블린이 아니라 왕국을 멸망시킨 그 군대와 싸워야 "왕국은 죽지 않았다"가 성립한다
- 아트 5종 신규 발주 절약 (고블린·늑대는 2장 이후 지역몹으로 이월)
- 보스 = **망령 기사장** (망령 기사 변형) — 적 킷 기획의 「무쇠 각오」 기믹 시험대

## 2. 1장 스토리라인 — 7비트

기획서 2장 뼈대(요새 확보 → 첫 재건 → 선봉장 격퇴) 준수. 대사는 구현 단계에서 집필,
여기서는 각 비트의 **목표·플레이 행동·보상**만 확정한다.

| # | 비트 | 이야기 | 플레이어가 하는 것 | 보상 (경제 연결) |
|---|---|---|---|---|
| 0 | 멸망의 밤 | 프롤로그 컷신 (나레이션+스틸) | 보기 (스킵 가능) | — |
| 1 | 선택받은 자 | 튜토리얼: 채집→성물 발현→첫 전투→세레스 조우 | 이동·채집 3회·가이드 전투 1판 | 시작 키트 |
| 2 | 폐허가 된 요새 | 요새 도착. 무너진 성문 앞 잔당 소탕 | 전투 1~2판 (해골 병사·궁수) | 목재·석재 뭉치 + **소환 제단 해금** |
| 3 | 첫 깃발 | 제단 건설 → 첫 소환(브란 확정) → 주점·주택 | 건설 3동 + 첫 뽑기 | 증표, 인구 해금 |
| 4 | 보급로를 뚫어라 | 벌목장 터를 점거한 선발대 축출 | 필드 탐색 + 전투 2판 (주술사 등판) | **벌목장·광산 해금** + 재화 |
| 5 | 어둠 속 습격 | 야습 격퇴 (생존전) → 정찰 나온 살수 추격 | 생존 스테이지 + 은신 학습전 | 대장간·상점 해금 + 장비 |
| 6 | 정령의 숨결 | 정령 제단에서 바람 정령의 힘 → 성물 각성 예고 | 필드 숨김길 + 제단 이벤트 | 여명 게이지 강화(각성 1) |
| 7 | 선봉장 격퇴 | 망령 기사장 결전 → "왕국은 죽지 않았다" | 보스전 (무쇠 각오 기믹) | 1장 클리어, 2장 예고 |

- 비트 2~7이 **메인 퀘스트 체인**: 항상 "다음 할 일" 1개가 화면에 떠 있다 (거점 세레스
  대화 or 필드 목표 마커). 길을 잃는 순간이 없게
- 전투의 "왜": 잔당 소탕(2)·보급로(4)·야습(5)·결전(7) — 전부 스토리 명분이 있다
- 건설의 "왜": 비트 진행 게이트 (제단 없으면 동료가 없고, 벌목장 없으면 성문 수리가 없다)

## 3. 경제 재조정 — "퀘스트가 주 수입, 채집은 보조, 방치는 저금통"

현재 실측: 채집 1회 3~5개 / 재생 180초 ↔ 1장 필요 건설비 합계 목재 ≈370·석재 ≈170.
채집만으로 약 90회 = 코미디. **채집을 상향하는 게 아니라 수입 구조를 바꾼다:**

| 수입원 | 역할 | 초기값 (전부 balance.js, 시뮬로 조정) |
|---|---|---|
| **퀘스트 보상** | 주 수입 — 각 비트가 다음 건설비를 대부분 준다 | 비트당 목재 60~120·석재 30~80 |
| **전투 드랍** | 반복 수입 — 스테이지 재화 드랍 신설 | 판당 목재/석재 8~20 (스테이지별) |
| 채집 | 보조 + **희귀재 전담** (강화석·철·약초) | 3~5 유지하되 희귀재 확률 추가 |
| 방치 생산 | 자리 비운 시간 보상, 2~3단계 업그레이드 재원 | 현행 유지 |

- 1단계 건설비는 유지 (퀘스트 보상이 커버) — 수치 하향보다 "받은 걸로 짓는" 체감이 낫다
- 고비용(성벽 2단계+, 3단계 건물)은 1장 후반~클리어 후 장기 목표로 남는 게 정상
- 검증: 시뮬레이터에 "1장 완주 경제 시나리오" 추가 — 비트 순서대로 수입·지출 재생해
  **막히는 구간(잔고 음수) 0**을 자동 확인

## 4. 필요한 시스템 (구현 스코프)

1. **퀘스트 체인 (메인만)**: 데이터 주도 `data/quests.js` — 목표(전투 승리/건설/채집/대화)
   + 보상 + 다음 비트. UI는 거점·필드에 "현재 목표" 1줄 + 완료 토스트. 서브퀘 구조는 안 만든다
2. **VN 대화 최소형**: 초상(있으면)+이름표+텍스트 박스+클릭 진행+로그. 선택지·호감도 분기 없음
3. **프롤로그 컷신**: 나레이션 텍스트 + 스틸 컷 (일러 오기 전엔 픽셀 실루엣 임시)
4. **새 게임 흐름**: 난이도 → 이름·직업 → 프롤로그 → 튜토리얼 (기획서 §621 그대로)
5. **스테이지 개편**: 현행 테스트 스테이지들을 비트 2~7의 정식 스테이지로 재편 + 재화 드랍
6. (적 킷 기획 승인 시) 보스 기믹·정예가 비트 5·7에 그대로 꽂힌다

## 5. 아트 의존성 (발주 대기함에 추가)

| 항목 | 필요 시점 | 비고 |
|---|---|---|
| **세레스 VN 초상** | 비트 1부터 등장 — 우선순위 1 | 현재 세레스 아트 0장 |
| 주인공 VN 초상 | 동시 | 가챠 일러 없음 — 전신 1장이면 초상 크롭 겸용 |
| 브란 VN 초상 | 비트 3 | 가챠 일러 크롭으로 임시 가능 |
| 전투 배경 (새벽 평원 낮/밤/보스방) | 비트 2~7 | 그래픽 개선 ②와 동일 발주 |
| 프롤로그 컷신 스틸 3~4장 | 비트 0 | 임시 연출로 시작, 나중에 교체 가능 |

## 6. 구현 순서 (승인 후)

1. 경제: 퀘스트 보상·전투 드랍 수치 + 1장 완주 경제 시뮬 (막힘 0 확인)
2. 퀘스트 체인 + 목표 UI → 비트 2~7 골격 (대화는 가placeholder)
3. VN 대화 최소형 + 새 게임 흐름 + 튜토리얼
4. 스테이지 재편 (+적 킷 병합)
5. 대사 집필 (톤: 밝음 베이스, 세레스=존댓말 총괄, 브란=무뚝뚝 죄책감)
6. 프롤로그 컷신 → 통합 검증 (새 게임→1장 클리어 완주 테스트)

## 7. 확인 포인트

2. §2 스토리 7비트 구성 (수정 의견 환영 — 비트 추가/삭제 이 단계가 싸다)
