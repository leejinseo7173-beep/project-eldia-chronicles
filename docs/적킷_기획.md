# 적 킷 보강 기획 — 전투 마무리 1단계

> 2026-08-23 작성. 상태: **사용자 검토 대기** (승인 후 구현).
> 근거 자료: `docs/적킷_설계보관.md` (9에이전트 설계·적대검증·실측 산출물, 2026-08-03).
> 그 문서의 수치는 M3 기준선에서 잰 것이라, **구조는 그대로 쓰되 수치는 오늘의
> 9칸 격자(전 칸 합격 상태)로 재검증**하며 넣는다 — 회귀 시 그 자리에서 조정.

---

## 1. 왜 하는가

지금 적은 "때리는 인형"이다 — 5종 중 3종은 액티브가 1개뿐이고, 광역기·정예·보스 기믹이
없어서 전투에 **배울 거리**가 없다. 이 기획은 기획서 §8의 설계 원칙
"지역 몹 = 전술 교사, 보스 = 기믹 시험"을 실제로 성립시키는 마지막 조각이다.

## 2. 만드는 것 3묶음

### ① 일반 적 광역기 3종 — "적도 광역을 쓴다"를 가르친다

| 적 | 신규 스킬 | 형태 | 노림수 |
|---|---|---|---|
| 해골 궁수 | 뼈살 관통 | 전체 물리, 저계수(단일의 45%) | 뭉친 파티 견제 |
| 그림자 살수 | 그림자 난도 | 전체 물리, 저계수 | 1턴에 못 잡았을 때의 벌 |
| 망령 기사 | 무덤의 한기 | 전체 마법 + **속박 1턴** | 피해가 아니라 발묶기가 본체 |

- 전부 **전체기(enemiesAll) 저계수** — 총 위협량은 안 올리고 형태만 바꾼다.
  (2체기는 2차 대상이 'HP 최저 처형 규격'이라 적에게 주면 하위 조합이 전멸 — 실측 확정)
- **아군 3명 이상 생존 시에만 사용** (소규모전·패잔 파티 보호 게이트)
- 광역은 도발·은신을 무시하므로 "도발 뒤에 숨으면 끝"이 아니게 된다

### ② 정예 3종 + 전용 스테이지 3개 — 파밍·서브퀘의 중간 보스

| 정예 | 베이스 | 킷 | 배우는 것 |
|---|---|---|---|
| 해골 대장 | 해골 병사 | 지휘의 골쇄 (2체 타격 + 속박·방어약화) | 디버프 해제·집중 화력 |
| 상급 주술사 | 암흑 주술사 | 암흑의 비호 (아군 보호막) + 암흑의 물결 (전체 마법) | 호위 먼저? 본체 먼저? |
| 처형 살수 | 그림자 살수 | 그림자 소멸 (타격 후 은신) + 처형 선고 (방어약화) | 은신 대처 (광역으로 지진다) |

- 스탯은 베이스 몹 그대로 + 역할 배수(HP만 크게, 공격은 오히려 0.95배) — 오래 버티지만
  한 방이 아프진 않은, "긴 호흡의 중간 보스"
- 전용 스테이지 3개 (해골 대장 토벌 / 상급 주술사 토벌 / 처형 살수 토벌) — M7 파밍·서브퀘 재료
- 정예는 스테이지당 1기 제한을 데이터 규칙으로 못박음

### ③ 보스 기믹 「무쇠 각오」 — 망령 기사장에 부여

**매 턴 처음 받는 피해 50% 감쇄** (HP 절반 아래로 떨어지면 해제).

- 플레이 퍼즐: **약한 일격(협공 유도·잽)으로 반감을 흘리고, 큰 스킬을 뒤에 꽂는다**
- 예상 결과 패널이 반감을 미리 보여줌 — "죽는다고 떠서 눌렀는데 안 죽음" 원천 차단
- 반감된 팝업은 하늘색 + 「무쇠 각오 -N」 표기 + 전용 효과음 (배우는 순간이 보이게)
- 저화력 파티 배려 2중: 4 미만 피해엔 발동 안 함 / HP 50% 이하에서 자동 해제
  (이거 없으면 455조합 중 일부가 60턴 교착 — 실측)
- 보스 체력 배수를 소폭 내려(11.0→10.2) 기믹의 유효 HP 증가(+8.6%)를 상쇄 — 체감 턴 수 유지
- M7 보스 6종의 기믹 시스템 기반이 이걸로 깔린다 (기믹 추가 = 데이터 1줄 + 판정 1케이스)

## 3. 안 만드는 것 — 그리고 승인이 필요한 지점

**해골 병사·암흑 주술사에게는 광역기를 주지 않는다.** 작업계획 2부 §3-4의
"마왕군 5종에 광역기 1개씩"과 어긋나므로 승인 필요:

- 병사: 액티브를 주는 순간 **반격을 안 맞게 되어**(반격은 일반공격 피격에만) 오히려
  오래 살아남고, 계수를 0.1까지 내려도 보스전이 불합격 — 실측으로 어떤 형태도 채택 불가
- 주술사: 딜 액티브를 주면 같은 이유로 안 죽어서, 마법사 주인공 보스전 승률 99%→55% 붕괴
- 재해석 제안: "5종 광역기" → "**실제로 발동하고 총 위협량을 올리지 않는 킷 보강**"
  (병사의 정체성 = 반격 맞아주며 달려드는 소모품, 주술사 = 힐·축복 지원 — 지금이 완성형)

## 4. 검증 계획

1. 단계별 델타 검사 — 수치 키만 추가(델타 0) → 킷 부여 → 기믹 → 정예, 각 단계에서
   기존 스테이지 회귀 없음을 확인
2. **9칸 격자 전 칸 합격 유지** (현재 상태가 기준선 — 여기서 후퇴하면 그 자리에서 조정)
3. 455조합 전수 스윕 — 승률 0% 조합이 늘지 않을 것
4. 예상 결과 ↔ 실제 실행 불일치 0 (저RNG 원칙)
5. 세이브 왕복 + 콘솔 에러 0

## 5. 확인 포인트 (승인 시 그대로 진행)

1. ②의 정예 스테이지 3개를 지금 스테이지 목록에 추가하는 것 (M7 전이지만 치트 콘솔·시뮬로 접근)
2. ③의 보스 기믹을 현행 망령 기사장전에 바로 거는 것 (1장 보스가 첫 기믹 시험이 됨)
3. §3의 "5종 광역기 → 3종 + 재해석" 승인
