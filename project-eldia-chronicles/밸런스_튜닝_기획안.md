# 밸런스 튜닝 기획안

> 작성 시점: M3 완료 직후. 구현 전 방향 확인용 문서.
> 수정은 전부 `balance.js` / `stages.js` 데이터 조정 + 파티 편성 최소 구현으로 이루어진다.

---

## 1. 진단 — 왜 지금 밸런스가 애매한가

### 1-1. 적이 너무 쉽게 죽는 직접 원인 (4가지)

**(A) 적 HP가 "일반공격 2방" 기준으로만 역산됐다.**
기획서 TTK 앵커는 "동레벨 일반 몹 = 딜러 2행동(**스킬1+일반1**)"인데, 실제 역산은 일반공격 2회로 되어 있다. Lv3 기준 실측:

| 상황 | 계산 | 해골 병사 HP 16 |
|---|---|---|
| 일반공격 | 12−4 = **8** | 2방 필요 ✓ 앵커대로 |
| 용사의 일섬(150%) | 12×1.5−4 = **14** | 1방+α |
| + 공격 강화(30%) | 12×1.3×1.5−4 = **19** | **1방컷** |
| + 이끄는 자(10%)까지 | 12×1.4×1.5−4 = **21** | **여유 1방컷** |

즉 스킬과 버프를 쓰는 정상 플레이에서는 앵커가 이미 깨져 있다.

**(B) 반격이 아군에게 일방적으로 유리하다.**
적이 일반공격할 때마다 아군이 공짜 반격(70%)을 넣는다. 적 5~6기가 때리면 아군은 가만히 있어도 턴당 30~50 피해를 준다. 게다가 아군 반격에는 치명타가 있고 적 반격에는 없다(기획: 적→아군 치명 없음). 방어전에서 "버티기만 했는데 적이 녹는" 현상의 주범.

**(C) 적 킷이 빈약하다.**
아군은 스킬 72종인데 마왕군은 8종이고 광역기가 없다. 주술사가 힐을 해도 아군 집중 화력 한 번이면 무의미하다.

**(D) 그 결과 "아군 피격 4~6대 생존" 앵커가 시험될 기회가 없다.**
적이 행동하기 전에 죽으니 긴장이 생기지 않는다. 버티기 스테이지에서 적 레벨을 올렸을 때만 긴장이 생겼던 것이 방증.

### 1-2. 추가 발견 — 연계 협공이 사실상 무의미하다 ★

M2에서 "연계 협공 = 전투의 핵심 재미"로 설계했는데, **뺄셈식 데미지 공식과 충돌해 실제로는 거의 피해가 안 나온다.**

브란(공 10)이 협공할 때: 계수 약 55% → `10 × 0.55 = 5.5`, 방어 4 차감 → **1.5 → 최소보장 적용 1~2 피해**.
본 공격이 8~14인데 협공이 1~2면 "이어 치는 보상"이 체감되지 않는다. 레벨이 올라도 방어 차감이 비례해 커지므로 구조적으로 개선되지 않는다.

**→ 협공 계산 방식 자체를 바꿔야 한다** (아래 3-3).

### 1-3. 구조적 공백 (사용자 지적)

**(E) 캐릭터 선택이 없다.**
파티가 `stages.js`에 하드코딩되어 있다. 치트 콘솔의 "무작위 파티"가 유일한 변형 수단.
→ **어떤 조합이 강하고 약한지 측정 자체가 불가능**하다. 밸런스 튜닝의 전제조건이 빠져 있다.

**(F) 육성 후 밸런스가 정의되어 있지 않다.**
기획서에 육성 4축의 **비중**(레벨 50 / 장비 25 / 한돌 15 / 각성 10%)은 있으나, 실제 수치 곡선과 "챕터별 적정 전투력"이 없다. 지금 전투는 전부 Lv3 고정이라 Lv30, Lv60에서 어떻게 되는지 아무도 모른다.
기획서 §14 안전장치 7항이 요구하는 "**챕터별 목표 전투력·경제 기준표**"가 미작성 상태.

## 2. 선행 작업 — 파티 편성 최소 구현

밸런스를 측정하려면 임의 파티를 만들 수 있어야 한다. **M5의 완전한 편성 화면이 아니라, 검증에 필요한 최소 기능만 먼저 만든다.**

- 전투 진입 전 간단한 편성 화면: 15명 목록에서 3명 선택(주인공 고정) + 진형 슬롯 순서
- 캐릭터별 레벨을 임시로 지정할 수 있게(개발용) — 육성 밸런스 검증에 필수
- 시뮬레이터가 임의 조합을 받도록 확장

이게 생기면 가능해지는 것:
- **455개 조합 전수 시뮬** (15명 중 3명 = C(15,3) = 455) → 지나치게 강한/약한 조합 자동 발견
- 직업 구성별 검증 (탱 없음, 힐 없음, 딜러만 등 극단 조합에서도 성립하는가)
- 사용자가 직접 파티를 짜서 플레이 → 체감 피드백

**이건 M5 작업의 선당김이며, 나중에 M5에서 UI만 다듬으면 된다.**

## 3. 전투 밸런스 수정안

### 3-1. 적 스탯 재역산 공식

앵커를 **"딜러가 스킬1+일반1로 처치"**로 정확히 재정의하고 역산한다.

```
일반몹 HP = (딜러 스킬 데미지 + 딜러 일반 데미지) × 보정
  · 딜러 기준 = 해당 챕터 권장 레벨의 전사/마법사 평균
  · 스킬 계수 150% 기준, 버프 미적용 상태
  · 보정 1.15 (버프·협공 여지를 남겨 1방컷 방지)
```

Lv3 예시: (14 + 8) × 1.15 ≈ **25** (현재 16 → 약 1.55배 상향)

역할별 배수(일반몹 HP 대비):
| 역할 | HP 배수 | 목표 |
|---|---|---|
| 일반몹 | 1.0 | 딜러 2행동 |
| 정예 | 2.5~3.0 | 파티 협력 4~6행동 |
| 보스 | 6~9 | 총력전 6~8턴 |

적 공격력은 "**아군 피격 4~6대 생존**" 앵커 유지(기사 8대+, 마법사 3대). 현재 수치가 이미 근접하므로 큰 조정 불필요.

### 3-2. 반격 비대칭 완화 (3안 중 택1 — 권장 A)

| 안 | 내용 | 장단 |
|---|---|---|
| **A (권장)** | 반격 위력 70% → **50%**, 대신 **아군 반격도 치명 없음** | 규칙이 단순해지고 좌우 대칭. "일반공격은 반격 위험"이라는 선택 구조는 유지 |
| B | 반격을 **턴당 1회**로 제한 | 다수전에서 무한 반격 방지. 규칙이 하나 늘어남 |
| C | 적에게 "반격 무시" 속성 부여 | 특정 적만 예외 — 나중에 기믹으로 쓰기 좋음 |

### 3-3. 연계 협공 재설계 (핵심) ★

협공이 체감되도록 **방어 차감 방식을 바꾼다.**

```
현행: 협공 데미지 = (공격력 × 55%) − 상대 방어      → 저계수라 거의 0
개선: 협공 데미지 = (공격력 − 상대 방어) × 55%      → 본 공격의 55%가 그대로 보장
```

Lv3 예시: 브란 협공이 `(10−4) × 0.55 = 3.3 → 3`. 본 공격 8의 40% 수준으로 **체감된다.**
표식 상태면 2배 → 6~7로 확실한 보상.

이 방식은 레벨이 올라도 비율이 유지되므로 구조적으로 안정적이다.

### 3-4. 적 킷 보강

- 마왕군 5종에 **광역기 1개씩** 추가 (암흑 주술사 = 적 전체 저계수 마법, 해골 궁수 = 2체 관통 등)
- **정예 변종 3종** 추가: 색·스탯 변형 재활용(기획서 §8 원칙) — 해골 대장, 상급 주술사, 처형 살수
- 보스 기믹 1종 실장: 1장 선봉장 "매 턴 첫 피격 반감" → 집중 공격·연계 학습 유도

## 4. 육성 밸런스 설계 (챕터별 기준표)

### 4-1. 챕터별 권장 레벨·장비 티어

| 챕터 | 권장 레벨 | 장비 티어 | 한돌 | 각성 |
|---|---|---|---|---|
| 프롤로그~1장 | 1~12 | T1 | 0 | 0 |
| 2장 | 12~22 | T2 | 0~1 | 0~1 |
| 3장 | 22~32 | T3 | 1~2 | 1 |
| 4장 | 32~42 | T4 | 2~3 | 1~2 |
| 5장 | 42~52 | T5 | 3~4 | 2~3 |
| 종장 | 52~60 | T6 | 4~5 | 3 |
| 엔드 콘텐츠 | 60 | T6 전설 +10 | 5(완돌) | 3 |

### 4-2. 육성 4축 기여 비중 검증 방법

기획서 목표: **레벨 50% / 장비 25% / 한돌 15% / 각성 10%**.
"전투력"을 다음으로 정의하고 시뮬로 검증한다.

```
전투력(CP) = (공격 또는 마력) × 2 + HP × 0.3 + 방어 × 1.5 + 속도 × 1
  · 직업별 주스탯 자동 판별(물리/마법)
  · 기준점: Lv1 무장비 무돌 무각성 = 100
```

Lv60 완성체를 100%로 볼 때 각 축이 만든 증가분의 비율이 목표치 ±5%p 안에 들어오도록 **장비 주스탯 곡선을 역산**한다. (한돌 +15%, 각성 +6%는 이미 곱연산으로 고정되어 있으므로 장비 곡선이 조정 변수)

### 4-3. 언더/오버 육성 체감 기준

| 상태 | 정의 | 목표 체감 |
|---|---|---|
| 언더 | 권장 레벨 −5 | 이길 수 있지만 아슬아슬(별1~2) |
| 적정 | 권장 레벨 | 별2~3 |
| 오버 | 권장 레벨 +5 | 무난, 별3 |
| 심한 오버 | +10 이상 | 소탕 가능 수준 |

파밍으로 과도하게 강해지는 걸 막는 장치는 이미 있다(재화 격리 — 방치 생산은 재건 자원만).

## 5. 난이도 목표 정의

**사용자 결정(2026-07-31)**: 아래 "무난하게" 수치를 **잠정 기준**으로 먼저 맞추고,
직접 플레이해 본 뒤 체감 피드백으로 최종 조정한다. → 튜닝을 2단계로 진행:
1차(잠정 기준까지 자동 튜닝) → 사용자 플레이 테스트 → 2차(체감 반영 미세 조정).

시뮬레이터의 **합격 기준**이 될 수치. 노말 난이도, 적정 육성 상태 기준.

| 전투 유형 | 승리 시 아군 최저 HP | 소요 턴 | 비고 |
|---|---|---|---|
| 일반 전투 | 55~70% | 3~4턴 | 무난하게 이기되 무피해는 아님 |
| 정예 | 40~55% | 4~6턴 | 스킬 운용 필요 |
| 보스 | 20~40% | 6~8턴 | 첫 도전에 질 수도 있음 |
| 버티기 | — | 규정 턴 | 전멸 위기 1~2회 |

난이도 보정: 이지 = 위 수치 +15%p 여유 / 하드 = −15%p (+ 적 스탯 +15%는 기존대로)

**현재 상태는 "일반 전투 최저 HP 88%"로 목표치를 한참 웃돈다.**

## 6. 검증 방법 (시뮬레이터 확장)

1. **조합 전수 시뮬**: 455개 파티 조합 × 각 스테이지 → 승률·최저 HP 분포. 상·하위 5% 조합을 이상치로 리포트
2. **육성 단계별 시뮬**: 챕터별 권장 레벨 ±5로 돌려 4-3의 체감 기준 충족 확인
3. **합격 기준 자동 판정**: 5장의 목표 범위를 시뮬 통과 조건으로 코드화 — 수치를 고칠 때마다 즉시 판정
4. **회귀 방지**: 기준을 통과한 수치 세트를 스냅샷으로 저장, 이후 변경 시 비교

## 7. 작업 순서

| 순서 | 작업 | 비고 |
|---|---|---|
| 0 | 보충 감사 (로직·AI 심층 리뷰) | 버그가 밸런스 문제로 위장되는 것 방지 |
| 1 | 파티 편성 최소 구현 | 측정의 전제조건 |
| 2 | 시뮬레이터 확장 (조합 전수·합격 판정) | 튜닝 도구 |
| 3 | 협공 계산 방식 수정 | 핵심 재미 복구 |
| 4 | 적 스탯 재역산 + 반격 조정 | 본 튜닝 |
| 5 | 적 킷 보강 (광역기·정예) | 전투 다양성 |
| 6 | 육성 곡선 설계 + 기준표 작성 | 장기 밸런스 |
| 7 | 전수 시뮬로 검증·미세 조정 | 합격까지 반복 |

3~5번이 끝나면 사용자 플레이 테스트로 체감을 확인하고, 그 피드백으로 6~7번을 마무리한다.
