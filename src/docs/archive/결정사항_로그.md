# 게임 기획 확정 사항 로그
(최종 기획서·프롬프트의 원천 자료. 대화로 확정될 때마다 갱신)

## 1. 프로젝트 개요
- 장르: 정통 판타지 수집형 전술 RPG (필드 탐험 + 왕국 재건 + 캐릭터 수집/교감)
- 플랫폼: 웹 브라우저 (HTML/JS, 추후 설치형 포장 가능)
- 규모: 중대형 — 스토리 8~12시간 + 반복 콘텐츠
- 개발 방식: 클로드 코드에게 최종 프롬프트로 전달 예정
- 그래픽: 코드 생성 픽셀아트 (외부 에셋 비의존)

## 2. 세계관·스토리 (뼈대만 확정, 세부는 E단계)
- 컨셉: 정통 용사물 × 몰락한 왕국 재건
- 아스텔 왕국(가제), 마왕 발게로스(가제)에 의해 3년 전 멸망
- 주인공: 변방 출신, 성물 아스칼론(가제)에 선택받은 용사. 전투 참여 고정 멤버
- 거점: 여명 요새(가제) — 왕녀 리네트(가제)와 재건
- 뽑기 명분: 왕의 인장으로 흩어진 영웅의 맹세를 소집
- 톤: 밝음 베이스 + 진지한 순간
- 챕터: 5지역 + 최종던전(마왕성)
  - 1장 새벽 평원(바람) / 2장 잿불 화산령(불) / 3장 서리 호수(물) / 4장 고요의 대삼림(땅) / 5장 왕도 폐허(빛/어둠) / 종장 마왕성(어둠)
- ※ 이름은 전부 가제. 캐릭터·지역·대사 등 세부 설정은 나중에(E단계)

## 3. 주인공
- 이름: 플레이어 입력 (기본명 제공, 8자 제한)
- 외형: 남/여 선택
- 직업: 3택 — 검사(근접 밸런스) / 마법사(원거리 광역) / 궁수(원거리 단일·기동)
  - 성물 아스칼론이 자질에 맞는 무기 형태로 발현하는 설정
- 성장: 성물 각성 5단계 (챕터 클리어마다). 각성 시 전용 스킬 획득 + 외형 변화
- 속성: 무속성 시작 → 각성마다 속성 모드 해금 (1장 바람 → 2장 불 → 3장 물 → 4장 땅 → 5장 빛)
  - 출격 준비 화면에서 성물 속성 선택 (전투 중 변경 불가)
- 등급 개념 없음 (고정 멤버)

## 4. 캐릭터 로스터 (15명, 분배 확정 / 세부 설정은 E단계)
- 파티: 주인공 + 뽑은 캐릭터 3명 = 4인

## 5. 속성 체계
- 6속성: 불/물/바람/땅 + 빛/어둠(희귀)
- 상성: 불→바람→땅→물→불 순환. 유리 1.3배 / 불리 0.7배 / 그 외 1.0배
- 빛↔어둠 상호 1.3배. 무속성은 전부 1.0배
- 적: 지역 속성 몹 + 전 지역 공통 어둠 마왕군
- UI: 유닛 속성 아이콘, 타겟 선택 시 유리▲/불리▼ + 예상 데미지 표시

## 6. 전투 (팀 턴제 확정)
- 팀 턴제 (내 팀 4명 자유 순서 → 적 팀), 8×8 격자, 아군 4 vs 적 3~6
- 전투 시작 전 배치 단계 (시작 구역 내 위치·방향 지정)
- 방향: 측면 1.2배 / 배후 1.5배+반격불가
- 협공: 공격 대상 반대편·측면 인접 아군이 자동 추가타 (위력 50%)
- 스킬 구조: 일반공격1 + 액티브2(쿨타임) + 패시브1. 각성 시 스킬 진화
- 전투 길이: 3~5분 (보스전만 크게)
- 승리조건 변형: 전멸/보스만/N턴 버티기/도달
- 별점: 별1~3 (클리어/전멸없음/N턴내). 별3 파밍 전투만 소탕 가능
- 편의: 2배속, 오토, 소탕
- 패배 페널티 없음 (재도전/귀환)
- 난이도: 이지/노말/하드 3단계
- 전투 소모품 사용 = 행동 소모, 전투당 3회 제한

## 7. 스탯·전투 계산 (A단계 확정분)
- 기본 스탯 6종: HP / 공격(물리) / 마력(마법 위력+마법 방어+치유량) / 방어(물리 방어) / 속도(치명 관여) / 이동력
- 사거리는 스탯이 아닌 무기·스킬 속성
- 데미지 공식(뺄셈식+최소보장):
  물리 = 공격×스킬계수×배율 − 방어 / 마법 = 마력×스킬계수×배율 − 마력 / 치유 = 마력×계수
  스킬계수: 일반 100%, 액티브 120~250%. 배율 = 상성×방향×치명 곱연산. 최소 보장 = 공격(마력)의 10%
- 계산 순서 고정: 계수→상성→방향→치명→방어차감→최소보장→정수 반올림
- RNG 정책 = ② 저RNG: 회피/미스 없음(항상 명중), 치명타만 존재
  치명타율 = 직업 기본치 + (내속도−상대속도)×1% + 장비 (0~50%), 배율 1.5
  직업 기본치: 도적15/궁수10/전사7/기사·마법사·성직자5%. 적→아군 치명 없음
- 반격: 일반공격 피격 시 생존+사거리 내면 자동 반격(위력 70%). 스킬 피격·배후 피격은 반격 불가
- 협공: 위력 = 협공자 일반공격의 50% + 속도 비례 보정. 협공엔 반격·치명 없음
- 턴 행동: 이동(0~이동력)→액션(공격/스킬/아이템/대기)→방향선택(4방향)→종료. 액션 후 재이동 불가, 액션 확정 전 이동 취소 가능
- 이동/거리: 상하좌우(대각선 없음), 맨해튼 거리. 아군 통과 가능·정지 불가, 적 통과 불가
- 오브젝트: 파괴 가능 장애물(드랍 가끔) + 파괴 불가 지형. 지형 스탯 효과는 없음
- 스킬 개수: 동료 = 일반1+액티브2+패시브1 (4개, 각성 시 진화). 주인공 = +성물 스킬1 (5개, 성물기는 속성 모드별 — 직업3×속성5=15종)
- 쿨타임: 전투 시작 시 전 스킬 사용 가능, 아군 팀 턴 시작마다 1 감소
- 버프/디버프: 동명 중첩 불가·지속 갱신. 범위 규격: 단일/십자/직선관통/주변8칸/원형2
- 전투불능: 전투 중 부활 수단으로만 복귀, 전투 종료 시 전원 완쾌
- 스킬 사용 UX: 유닛 클릭→이동→액션 메뉴→스킬 카드(쿨 표시)→사거리·범위 미리보기+정확한 예상 데미지·처치 표시→발동→방향 선택. 우클릭/ESC 단계별 취소. 마우스 완결 + 단축키(A/S/1~3/Space/ESC)
- 오토 스킬 로직: 쿨 되면 최적 대상 사용, 힐은 HP60% 이하 시. 오토는 수동보다 약간 비효율이 정상
- 구현 원칙: 정수 연산 / 시드 랜덤(재현 가능) / 로직·렌더링 분리(소탕·오토·자동 밸런스 시뮬 가능) / 캔버스+스프라이트 프리렌더+오브젝트 풀링 / 이동 범위 BFS

## 7-3. C단계 확정분 (상태이상·스킬)
- 스킬 효과 규격 추가: 다단히트(예 85%×2, 치명은 히트별 판정) / 밀치기(1칸, 벽·장애물 충돌 시 +50% 추가 피해) / 순간이동(이동력 무시)
- 상태이상 8종: 화상(시전자 마·공 30% 도트 2턴) / 둔화(이동-2, 2턴) / 속박(이동불가 1턴) / 기절(행동불가 1턴, 희소 사용) / 공격약화(-30% 2턴) / 방어붕괴(-30% 2턴) / 표식(피격 시 협공 위력 2배, 2턴) / 도발(1턴)
- 버프 6종: 공격강화(+30% 2턴) / 철벽(방어+40% 2턴) / 보호막(마력 150% 흡수, 최대 3턴) / 재생(마력 50%/턴, 2턴) / 신속(이동+2, 2턴) / 은신(1턴, 광역 피격 가능, 도적 전용)
- 처리: 팀 턴 시작 시 도트·지속 감소. 동명 중첩 불가·갱신. 보스는 기절·속박·도발 면역(표시)
- 동료 15명 스킬 확정 (슬롯별 일반1+액티브2+패시브1, 상세는 별도 스킬표 — C01~C15 전원 설계 완료)
  - C03 성녀 수정: HP 소모로 전투불능 불가(최소 1) / 성역은 자신 중심·자신 포함 / 오토 시 HP30% 이하면 소모 스킬 금지 / 각성 시 소모율 10→7→5%
- 각성 진화 규칙: 1각=액티브1 강화, 2각=패시브 강화, 3각=액티브2 진화+개명
- 주인공 스킬 구조: 5슬롯 = 직업 기본 4개(일반+액티브2+패시브) + 성물 스킬 1개
  - 성물 스킬 3종(직업별): 검사 성검해방(십자 150%) / 마법사 성장해방(사거리3 원형2 130%) / 궁수 성궁해방(직선 전체관통 140%), 쿨 3
  - 속성 모드 공통 효과: 바람=밀치기 / 불=화상 / 물=둔화 / 땅=속박 / 빛=대어둠+30%. 데미지 속성도 모드를 따름
  - 속성 모드 해금 = ★B안 「정령왕의 시련」: 각 지역 필드의 정령 제단에서 특수 규칙 시련 전투를 클리어하면 해금 (탐험 보상, 도전 타이밍 자유). 빛은 5장 관련. 시련은 변형 룰 전투(예: N턴 내 목표 파괴)
  - 주인공은 한계돌파 없음. 성물 각성(시련 클리어)마다 성물 스킬 강화 + 외형 변화

## 7-4. B단계 확정분 (적 설계)
- AI 성향 5종: 돌격형(직진) / 사수형(사거리 유지, 저방어 타겟) / 교활형(측면·배후, 유리몸 우선) / 수호형(지정 유닛 곁 2칸, 도발) / 지원형(치유·버프 우선)
- 타겟 점수식: 처치가능+100 / 예상데미지×1 / 상성유리+15 / 배후·측면+20 / 거리−3×칸. 성향별 가중치 조정. 도발 최우선, 은신 제외
- 적 행동 순서: 지원→사수→교활→수호→돌격. 광역기는 2체 이상, 힐은 아군 60% 이하 시. 적도 협공 가능
- 난이도 AI: 이지(배후 안 노림·타겟 랜덤·협공 없음) / 노말(표준) / 하드(배후 강화+집중 공격+스탯 +15%)
