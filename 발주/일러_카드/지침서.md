## 1. 무엇을 뽑나

수집형 뽑기 화면의 **카드 일러스트**. 아래 4명 중 **한 명만** 골라 **전신 세로 1장**.
(전신 1장이면 카드용 상반신 크롭과 나중 대화 화면 초상까지 겸용합니다)

## 2. 규격 — 어기면 못 씁니다

| 항목 | 값 |
|---|---|
| 구도 | **전신 세로**, 정면에서 살짝 왼쪽으로 튼 3/4, 당당한 히로익 포즈 |
| 캔버스 | 세로형이면 됨 (512×768 이상 권장) |
| 배경 | **순백 #ffffff 단색** — 배경 효과·후광 금지 (게임이 얹습니다) |
| 외곽선 | 진한 검정 |
| 잘림 | 팔·다리·무기·망토 끝까지 전부 캔버스 안에 |
| 글자 | **그림에 파일명·텍스트 넣지 말 것** |

## 3. 공통 스타일 프리픽스 — 프롬프트 맨 앞에 항상

```
16-bit JRPG pixel art, SNES era, Vanillaware / Tactics Ogre style,
full body, 4-head-tall heroic proportions, thick black outline,
limited palette with 2-3 shading steps,
crisp pixels, no anti-aliasing, pure white background, centered, full body visible
```

네거티브:

```
chibi, super deformed, 3d render, blurry, anti-aliased, soft shading,
gradient background, transparent background, cropped, cut off limbs,
text, watermark, multiple characters, photorealistic
```

## 4-2. NPC — 왕녀 세레스 (거점 총괄·스토리 내레이션 파트너)

카드가 아니라 **대화 화면 초상·스토리용**이지만 규격·화풍은 위와 완전히 동일합니다.
전신 세로 1장이면 초상 크롭까지 겸용. 무기는 없습니다.

★2026-08-24 **1호 승인 완료** (assets/illust/npc_seres.png) — 아래는 승인본 기준으로 갱신된
확정 외형입니다. 재발주·추가 포즈 때 이대로 유지하세요:

```
last princess of a fallen kingdom, early twenties, regal but hardworking
wartime leader, golden blonde hair in an elegant updo with a silver tiara,
white and deep navy royal gown with gold embroidery, blue gem brooch,
ceremonial royal sword worn at her belt (she does not fight),
kind but resolute expression, standing gracefully
```

- 색: 왕국 테마 그대로 — 남색 `#283257`+`#3c4f82`, 금 `#f2d251`+`#c9992e`, 백 `#f2ecdd`
- 세라핀(금발 풀어헤침)과는 **업두+티아라**로 구분한다
- 허리의 의전용 검 = 왕가의 유산 (본인은 싸우지 않는다 — 서사 소품)
- 표정이 핵심: "지쳤지만 꺾이지 않은" — 멸망 후 3년을 버틴 왕녀
