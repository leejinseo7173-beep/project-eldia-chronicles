# DECISIONS.md — 미정 사항 결정 기록

> 기획서에 없는 세부 사항을 스스로 결정한 근거 로그 (개발 프롬프트 "미정 사항 처리 규칙").

## M1 코어

- **RNG 알고리즘 = xmur3(문자열 해시) + mulberry32**: 의존성 없이 수십 줄로 구현 가능하고 통계 품질이 게임용으로 충분하며, 32bit 정수 상태 하나만 저장하면 세이브에서 완전 재현 가능해서 선택.
- **RNG 상태 저장 API(getState/setState) 선제 포함**: M2 이후 전투 리플레이·시뮬 재현에 필수라 코어 단계에서 계약을 고정.
- **세이브 키 구조 = `eldia:save:{슬롯}` / `eldia:save:{슬롯}:auto` / `eldia:settings`**: 슬롯 3 + 슬롯별 자동저장(기획서 §15)을 localStorage 키 네임스페이스로 직역. 포맷에 `version` 필드를 두고 마이그레이션 지점을 미리 마련.
- **이어하기 = 수동/자동 중 더 최근 저장본 자동 선택**: 선택 UI를 하나 줄이고 "가장 최근 진행"이라는 직관과 일치. 크래시 복구도 자동 커버.
- **내보내기 포맷 = 사람이 읽을 수 있는 JSON**(수동+자동 동봉): 싱글 게임이라 난독화 이득이 없고, 버그 리포트·백업에 유리.
- **새 게임 시드 = `eldia-{슬롯}-{Date.now()}`**: 플레이어마다 다른 여정을 보장하면서 세이브에 시드가 남아 전체 재현 가능. (Math.random 미사용 규칙 준수)
- **정수배 스케일링 예외**: 창이 960×540보다 작을 때만 비율 유지 축소 허용. 정수배만 고집하면 작은 창에서 화면이 잘리기 때문. 창이 충분히 크면 항상 정수배 — 수동 배율(2배/3배)이 창을 초과하면 창에 들어가는 최대 정수배로 클램프한다 (비정수 축소 금지).
- **Galmuri 폰트는 아직 미동봉**: 파일 다운로드는 사용자 승인 필요 사항이라 M1은 `Galmuri9 → Malgun Gothic → monospace` 폰트 스택 폴백으로 처리. 폰트 파일을 `assets/fonts/`에 넣으면 @font-face 연결 예정 (승인 대기).
- **타이틀 화면 픽셀아트 = 240×135 저해상도로 그린 뒤 4배 정수 확대**: 도트가 굵은 픽셀아트 룩을 내면서 프리렌더 비용 최소화. 시드 RNG(`title-bg`)로 그려 항상 같은 그림.
- **덮어쓰기/삭제 확인 모달의 기본 포커스 = "아니요"**: 파괴적 동작 실수 방지.
- **개발 콘솔 토글 = `(백쿼트)/F1**: 한국어 키보드에서도 안정적인 물리 키 코드(e.code) 기준. F5는 브라우저 새로고침과 충돌하므로 수동 저장은 S 키로.
- **효과음 5종(이동/결정/취소/불가/저장)만 M1에서 구현**: AudioContext는 첫 사용자 입력 때 생성(브라우저 자동재생 정책으로 인한 콘솔 경고 방지). BGM·전투음은 M8.
- **UI 공용 문자열(챕터·직업 라벨 등)은 `src/data/strings.js`**: 데이터 주도 원칙을 UI 표기에도 적용, 화면 간 표기 불일치 방지.
- **balance.js에 기획서 확정 수치(상성·방향·치명·스탯표·상태이상·뽑기 등)를 선입력**: M2 이후 매직 넘버가 코드에 스며드는 것을 원천 차단하기 위해 코어 단계에서 단일 지점을 먼저 확립.

## M1 리뷰 반영 (다각도 코드 리뷰 확정 9건 중 8건 수정, 1건 안건화)

- **새 게임 시작 시 슬롯 완전 초기화**: `startNewGame`이 `deleteSlot` 후 저장 — 이전 여정의 자동저장이 새 여정에 섞여 남는 문제 제거.
- **키 입력 필터**: 수정키(Ctrl/Meta/Alt) 조합은 무시(브라우저 단축키 충돌 방지), OS 키 반복은 방향키만 허용(Enter 홀드로 빈 슬롯에 새 게임이 생성되는 사고 방지).
- **세이브 스키마 검증**: `migrate`가 version 정수 검사 + 필수 필드(heroName/seed/chapter/playTimeSec) 타입 검증. 손상 파일 가져오기·손상 localStorage 로드를 차단.
- **타이틀 배경 팔레트 준수**: 배경 픽셀아트를 공용 팔레트 32색 내부 색으로 재작업 (기획서 §16 "팔레트 = 아트 통일성의 핵심" 준수, 팔레트 이탈 선례 차단).
- **changeScene 큐잉**: 페이드 중 전환 요청은 드랍하지 않고 목적지 교체 — M3 오토/소탕의 프로그램적 씬 체인에서 무음 소실로 인한 소프트락 예방.
- **플레이 시간 일괄 누적**: 씬의 `isGameplay` 플래그를 보고 Game.update가 한 곳에서 누적 — 이후 게임플레이 씬마다 누적 코드를 복제하다 누락하는 사고 방지.
- **개발 콘솔 슬롯 삭제 시 타이틀 캐시 동기화** + 이어하기 진입 시에도 항상 슬롯 목록 갱신.
- **Galmuri 폰트 동봉(해결)**: 사용자 승인 후 jsDelivr 공식 CDN(galmuri@2.40.3)에서 Galmuri11/Galmuri11-Bold/Galmuri9 woff2를 `assets/fonts/`에 동봉하고 @font-face 연결. 본문 = Galmuri11, 중간 크기 = Galmuri9 2배.
- **폰트 크기 스냅 티어**: 픽셀 폰트는 원본(9/11px)의 정수배에서만 선명하므로 `font()`가 요청 크기를 11/18/22/33/44/55 티어로 스냅. 호출부는 의도 크기를 쓰고 실제 렌더 크기는 한 곳에서 통제.
- **file:// 직접 실행 가드**: index.html을 더블클릭하면 ES 모듈이 CORS로 차단되어 검은 화면이 되므로, file:// 감지 시 실행 방법 안내를 표시. 더블클릭 실행용 `게임실행.bat`(서버 기동+브라우저 열기) 동봉.

## M2 전투 프로토타입

- **협공 속도 보정 = 속도 1당 +0.5%p** (속도 10 = 위력 55%): 기획서의 "50% + 속도 비례 보정"을 구체화. 도적·궁수의 협공 가치를 살리되 과하지 않게.
- **협공은 방향 배율 미적용(정면 고정)·치명 없음·반격 없음**: 기획서 명시(치명·반격 없음)에 방향 미적용을 추가 — 본 공격의 배후 보너스와 이중 보상 방지. 협공 위력 강화는 M3의 표식(2배)이 담당.
- **반격은 항상 정면 판정**: 공격자는 공격 시 대상을 자동으로 바라보므로 반격이 배후·측면일 수 없음. 반격 치명은 허용(아군 반격만 — 적→아군 치명 없음 규칙이 우선).
- **대각 동률(|dx|=|dy|) 방향 판정 = 측면**: 4방향 배율 체계에서 대각은 정면도 배후도 아니라는 직관.
- **최종 데미지 최소 1 보장**: 최소 보장(공격력 10%)이 반올림으로 0이 되는 저레벨 구간 방지.
- **배치 단계는 M3로 연기**: CLAUDE.md의 M2 정의(이동·공격·방향·협공·반격·2vs2)에 배치가 없어 고정 시작 위치 사용. M3 별점·승리조건 변형과 함께 구현.
- **M2 적 AI = 돌격형만**: 5성향은 M3. 협공·반격 로직은 완전 대칭(적도 협공·반격 가능 — 기획서 "적도 협공 가능").
- **전투 중 저장 미지원**: 저장은 거점·타이틀 시점만(기획서 §15 자동저장 시점과 일치). 전투 상태는 RNG 인스턴스를 포함하므로 직렬화는 필요해지는 시점(M9 파일 저장)에 추가.
- **전투 셀 64px** (= 32×32 스프라이트의 2배 정수 스케일): 8×8=512px 격자가 960×540에서 좌우 정보 패널 공간을 남기는 최대 정수배.
- **해골 병사 스탯 역산**: 정면 일반공격 2회로는 못 잡고(9×2=18 < HP20) 측면·배후·협공을 쓰면 2행동 처치가 되도록 — M2의 학습 목표(방향·협공이 이득임을 몸으로 느끼기)를 스탯으로 강제. 아군 생존은 주인공 기준 5~6대.

## M2 리뷰 반영 (다각도 리뷰 확정 10건 전부 수정)

- **협공자·반격자도 방향 전환을 로직에 영구 반영**: 연출로만 돌리고 로직은 안 돌리면 재생 종료 시 방향이 스냅되는 잔상이 남고, 화면과 실제 판정이 어긋난다. 협공/반격하러 돌아선 유닛은 그 방향으로 남는 것이 전술적으로도 자연스러움(배후 노출 리스크 = 협공 배치의 대가).
- **enemyPhase의 유닛 스킵은 continue**: 승패 확정만 팀 턴 중단 사유. 죽었거나 계획 불가한 적 1기가 나머지 적 턴을 삼키던 잠복 결함 수정 (M3 다수 적·원거리에서 표면화 예정이던 것).
- **적 AI 공격 위치 = 맨해튼 링 전체 열거**: 십자 4방향만 보던 것을 |dx|+|dy| ∈ [min,max] 전체로 — M3 원거리 적(사거리 2~3)이 데이터 추가만으로 올바르게 동작해야 하는 계약(데이터 주도) 이행. 공격 판정도 이동 후 실거리 기준으로 단순화.
- **최종 데미지 하한을 BALANCE.damage.floor로 이동**: 절대 규칙 2(모든 밸런스 수치는 balance.js) 준수.
- **BattleScene.enter()에서 pendingEnemy 등 잔존 상태 전부 리셋**: 씬 싱글턴 재사용 구조에서 적 턴 대기 타이머가 새 전투로 새어 들어가 적이 선제 행동하던 버그 수정.
- **'대기' 경유 방향 선택은 ESC/우클릭으로 액션 메뉴 복귀 허용**: 아무 것도 실행되지 않았으므로 취소 가능해야 함(기획서 §6 단계별 취소). 공격 경유는 이미 실행됐으므로 취소 불가 유지.
- **방향 선택 진입 직후 0.2초 화살표 입력 유예**: 이동/타겟 단계에서 누르고 있던 방향키의 OS 반복이 방향을 즉시 확정해버리는 오입력 방지.
- **방향 선택 버튼 화면 내 클램프 + 패널 위에 렌더**: 가장자리 행에서 버튼이 화면 밖으로 잘리거나 정보 패널에 가려지던 문제 — 마우스 완결 조작(절대 규칙 8) 복원.
- **턴 표시는 재생 완료 기준(statusLine)**: 로직이 선반영되어 적 턴 연출 중에 "다음 턴"으로 미리 넘어가 보이던 표시 어긋남 수정.
- **협공 전용 효과음 배선**: 만들어 두고 안 쓰던 'assist' 차임을 협공 임팩트에 연결 — 본 공격과 청각적으로 구분.

## M2 전투 구조 전환 — JRPG 사이드뷰 (사용자 지시)

- **8×8 격자 전투를 사이드뷰 고정 진형으로 전면 교체**: 사용자가 "좌우에 있는 JRPG 형태"를 명시적으로 요청. 기획서·CLAUDE.md의 전투 관련 조항을 전부 개정했고, 별도 사본(-2 폴더)은 사용자 지시로 무시·미참조. 격자 버전 전체는 커밋 b455367에 보존.
- **연계 협공으로 협공 재설계**: 위치 기반 협공(반대편·측면)의 대체 — 같은 팀 턴에 이미 공격받은 대상을 다른 아군이 다시 치면 직전 공격자가 자동 추가타(50%+속도 보정, 치명·반격 없음, 공격 1회당 1회). "누가 먼저 치고 누가 잇는가"의 순서 퍼즐로 협공의 재미를 계승. 표식(2배)·궁수 협공 패시브와의 시너지 유지. 연계 추적은 팀 턴 단위로 리셋.
- **반격 = 일반공격 피격 후 생존 시 무조건** (사거리·배후 조건 소멸): "일반공격은 공짜지만 반격 위험" 선택 구조 유지. 스킬·협공 피격은 반격 불가.
- **스킬 대상 규격 6종으로 개정**: 적 단일/적 2체(대상+HP 최저 자동)/적 전체/아군 단일/아군 전체/자신. "적 2체"의 추가 대상을 HP 최저로 고정해 무작위 대상 없이 저RNG 원칙(계획 100% 실행) 유지. 격자 범위(십자·관통·원형)를 쓰던 스킬 45종 전부 재배정.
- **이동력·사거리 스탯 삭제 (6종→5종)**: 도적·궁수의 기동 정체성은 속도로 계승(치명·협공 위력·상태이상 관여). 실피 패시브는 "자신보다 느린 적에게 +20%"로, 리안 바람걸음은 속도 버프로 재해석.
- **상태이상 재정의**: 둔화 = 속도 −30% / 속박 = 일반공격 외 행동 불가 / 신속 = 속도 +30%.
- **보스 기믹 격자 의존 2종 교체**: 1장 선봉장 "정면 반감" → "매 턴 첫 피격 반감"(집중 공격·연계 튜토리얼), 4장 수호자 "방향 회전" → "약점 속성 순환". 종장 카르노스 2P도 약점 순환으로.
- **해골 병사 사이드뷰 재역산**: HP [12,+2] — 동레벨 주인공 일반공격 정확히 2회. 혼자 잡으면 반격을 더 맞고, 나눠 치면 연계가 마무리 — 집중 공격 학습 유도. 생존 앵커(주인공 5~6대)는 유지.
- **스테이지 배치는 src/data/stages.js**: 전투 씬은 스테이지 ID만 받아 조립 — 콘텐츠 추가가 데이터 추가로 끝나는 계약을 M2부터 고정.
- **일반공격 유효성은 canAttack 단일 관문**: 불법 호출은 RangeError — UI·오토·시뮬 어느 경로도 규칙 우회 불가.
- **전투 스프라이트 3배 정수 확대(96px)**: 사이드뷰 4vs4가 960×540에서 겹치지 않는 최대 정수배.
- **에셋 방향 = 코드 생성 유지 (사용자 확정, 2026-07-30)**: 캐릭터·배경·사운드 전부 기획서의 '외부 에셋 제로' 원칙대로 코드 생성으로 진행. 단 **M6 수직 슬라이스에서 VN 초상(96×96×15명×표정3) 실물을 보고 재평가** — 품질이 부족하면 초상·타이틀 일러스트·BGM만 외부/AI 에셋으로 보강하는 혼합안을 그때 검토. 생성 지점이 일원화되어 있어 교체 비용은 낮다.
## M3 전투 완성

- **광역 스킬 계수 원칙 = 전체기 60~65%·2체기 80~85% (단일기 대비)**: 시뮬에서 성물 해방(전체 150%)+버프 스택이 적 전원을 한 방에 쓸어버리는 붕괴 확인 → 일괄 하향. 기획서 §3·§4의 명시 계수보다 낮지만, 기획서 헤더의 "모든 수치는 초기값이며 balance.js에서 일괄 조정" 원칙을 따름.
- **기절·속박은 적용 시 +1턴 내부 보정**: 상태 지속은 피해자 팀 턴 시작 틱에서 감소하므로, 보정 없이는 상대가 건 기절이 발동 전에 만료됨. 도트(화상·재생)는 틱 시 발동 후 감소라 보정 불필요 — 정확히 2회 발동.
- **도발 = 구현상 버프 분류**: 시전자 자신에게 걸어 적의 단일 공격을 강제하는 상태이므로 정화(디버프 해제) 대상이 아님. 보스 면역은 "보스가 도발 강제를 무시"로 처리.
- **화상 도트 = 시전자 공·마 중 높은 쪽 30%**: 기획서 "시전자 마·공 30%"의 구체화 — 물리·마법 시전자 모두 유효하게.
- **협공 트리거 = 적 단일 대상 데미지 스킬(일반+액티브)**: 광역기는 연계를 트리거·갱신하지 않음 — 광역+연계 이중 이득 방지. 협공 추가타 속성은 협공자 일반공격(물리/마법)을 따름. 반격도 반격자 일반공격의 물리/마법을 따름.
- **은신 전원 상태 등 극단 상황에서는 단일 지정 허용**: 대상이 아예 없어 행동 불가가 되는 소프트락 방지.
- **스테이지 적 레벨 오버라이드**: 정예·보스 역할과 버티기 위협은 적 개별 level 필드로 TTK 역산 (데이터 주도 — 코드 수정 없음). 버티기 스테이지는 5턴 내 전멸 불가 레벨로 설정해 생존 경로가 실제 승리 루트가 되게 함 (시뮬 승률 88%·평균 5.7턴 확인).
- **오토 우선순위 = 치유(60% 이하)→지원(보호막·버프·디버프)→공격 스킬(광역은 적 2체+)→일반공격(처치 가능>연계>점수식)**: 기획서 "오토는 수동보다 약간 비효율" 허용 범위. 세라핀 HP 30% 이하 소모 스킬 금지 반영.
- **전투 아이템 액션은 M5로**: 소모품·인벤토리가 M5 범위라 액션 메뉴에서 제외. 기획서 M3 정의에도 아이템 없음.
- **성물 스킬은 M3에서 무속성**: 속성 모드는 M4 정령 시련 해금 후. 데이터 훅(모드별 부가효과)은 유지.
- **시뮬 결과 해석 기준**: 4인 파티 vs 일반몹 5기가 평균 2턴 종료는 "딜러 2행동" 앵커의 산술적 귀결로 정상. 전투 길이 3~5분은 연출 시간+적 웨이브·구성(M4+ 콘텐츠)으로 달성.

## 전투 수치 표시 원칙 추가 (사용자 지시, 기획서 §6에 명문화)

- **모든 판단 근거를 숫자로 노출한다**: 저RNG(회피·미스 없음) 설계라 결과가 전부 계산 가능하므로, 플레이어가 추측하게 두지 않는다. 적 스탯도 아군과 동일하게 공개 — 정보 은폐로 난이도를 만들지 않는다.
- **미구현 항목 (다음 작업 시 반영)**:
  1. **스킬 카드에 실제 예상 수치** — 현재 "150%×2" 같은 계수만 표시. 실제 피해·치유·보호막 수치로 교체(계수는 보조)
  2. **유닛 정보의 실효 스탯 표시** — 현재 기본 스탯만 노출. 버프·디버프 반영값과 증감 표시(`공격 12 → 15 ▲`) 필요
  3. **도트 턴당 예상 피해량** — 화상 등의 실제 피해량이 정보 패널에 안 보임
  4. **보호막 잔량 수치** — 현재 바 형태만, 숫자 없음
  5. **★ 용어·효과 설명 툴팁** — 철벽·도발·은신 등 상태이상 14종, 스킬, 패시브, 스탯의 효과를 이름만으로는 알 수 없다. 마우스 오버 + 키보드 접근 경로 둘 다 필요
     - 툴팁은 **효과 설명 + 그 유닛 기준 실제 수치**(예: "공격·마력 +30% → 12 → 15, 남은 2턴")
     - **한계도 명시**: 도발이 광역기를 못 막음 / 은신이 광역기엔 맞음 — 모르면 속았다고 느끼는 지점
     - 설명 문구는 `data/statuses.js`·`skills.js`에 데이터로, 수치는 `balance.js`에서 채워 넣어 **수치 조정 시 설명이 자동 동기화**되게 (설명·실제 불일치 원천 차단)
     - `STATUSES`에 `desc` 필드 신설 필요 (`PASSIVES`에는 이미 있음)
- 이미 충족된 항목: 대상 선택 예상 결과 패널(피해·치명·협공·반격·처치·상성), 데미지 팝업, 상태 아이콘 남은 턴, 별점 조건 표시.

## M3 리뷰 반영 (확정 5건 + 자체 확인 3건 수정)

- **조건 치명 확정(급소 찌르기)을 예상치·오토 처치 판정에 반영**: 결정론적 확정은 예상 데미지에 정확히 표시(치명 100%) — 저RNG 원칙.
- **skillSelect 단계의 투명 토글 히트박스 제거**: 오토/배속 버튼이 안 그려지는 단계에서 주인공 성물 카드 클릭을 가로채던 문제(High) — 히트 테스트를 렌더 조건과 일치.
- **오토 ON 시 진행 중 수동 선택 정리**: action/skillSelect/target 단계에서 오토를 켜면 select로 정규화해 즉시 구동 — "오토 ON인데 멈춘 것처럼 보이는" 상태 머신 공백 해소.
- **상태 아이콘 칩에 남은 턴 표시** (기획서 §6). 보스 면역의 정적 아이콘 표시는 보스 UI가 생기는 M6에서.
- **하드 집중 가중치·패시브 HP 임계값을 balance.js로 이동** (절대 규칙 2): ai.hardFocusBonus, passives.c11_p/c08_p.hpThreshold.
- **보스 도발 면역은 "강제 무시"로만**: 자기 자신에게 거는 도발까지 applyStatus에서 막혀 수호형 보스가 자기 스킬을 못 쓰던 문제 수정 — 면역 처리는 validTargets(공격자가 보스면 도발 강제 무시)에서만.
- **도르간 방패 밀치기 공격 약화 1턴**: 스킬별 debuffTurns 오버라이드 추가 (기본 2턴과 다른 지속).
- **미완 리뷰 차원**: logic-bugs·ai-bugs 리뷰어가 세션 한도로 미실행 — 두 파일은 자동 테스트 36건+시뮬 320회로 커버됨. 필요 시 한도 리셋 후 추가 감사 가능.

- **기본 모션 세트는 M2 범위** (사용자 피드백 반영): "손맛이 M2의 성패" 기준상 캐릭터 기본 모션은 지금 — 호흡(2프레임, 유닛별 위상차)·돌진 중 달리기 프레임·타격 순간 공격 자세(무기 내지르기)·피격 넉백·전투불능 쓰러짐(회전+페이드). 스킬 파티클·협공 초상 컷인·보스 연출은 계획대로 M3~M8. 스프라이트 규격은 방향별 2프레임 + 공격 자세로 확장(필드 걷기 2프레임 스펙과 공용).
