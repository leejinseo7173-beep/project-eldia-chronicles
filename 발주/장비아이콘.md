## 1. 규격 — 어기면 못 씁니다

| 항목 | 값 |
|---|---|
| 구도 | **아이템 딱 하나**, 중앙 배치, 대각선(45°) 또는 정면 |
| 캔버스 | 정사각 512×512 이상 |
| 배경 | **순백 #ffffff 단색** — 배경 효과·그림자·바닥 금지 |
| 외곽선 | 진한 검정 |
| 잘림 | 칼끝·활끝까지 전부 캔버스 안에 |
| 글자 | **글자·워터마크 금지** |
| 손·캐릭터 | 사람·손 금지 — 아이템 단독 |

## 2. 공통 스타일 프리픽스 — 프롬프트 맨 앞에 항상

```
16-bit JRPG item icon, pixel art, ornate fantasy equipment,
thick black outline, vibrant jewel colors with glowing accents,
crisp pixels, single item centered at 45-degree angle,
pure white background, no text, whole item visible
```

네거티브:

```
photorealistic, 3d render, blurry, soft shading, multiple items,
character, hands, text, watermark, background scenery, shadow on ground,
cropped, cut off
```
